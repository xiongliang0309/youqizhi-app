# 古诗模块：单屏单首 + 翻页切换（循环）设计稿

## 背景

当前古诗列表采用网格卡片展示，在不同屏幕尺寸与长文本场景下容易出现视觉拥挤、内容溢出与交互焦点分散等问题。目标是改为“任意屏幕一次只展示一首古诗”，通过翻页切换，并且古诗内容高度不限制、随内容自适应。

## 目标

- 任意屏幕尺寸下一次只展示一首古诗（单屏单首）
- 支持翻页切换：左右滑动 + 底部吸底翻页条
- 翻页到边界时循环（最后一首 → 第一首，第一首 → 最后一首）
- 古诗正文高度不限制：随内容自然撑开；长诗通过页面纵向滚动阅读
- 保留搜索框：按标题/内容过滤后，在过滤结果集合内翻页

## 非目标

- 不做“卡片内部滚动”与“固定高度卡片”
- 不引入新的第三方 UI 库（沿用现有 React + Tailwind + framer-motion）
- 不在本次实现中引入复杂的书页翻转 3D 动效

## 信息架构与页面结构

### 顶部区域（Header）

- 返回：返回分类
- 标题：古诗诵读
- 右侧：进度显示（示例：第 6 / 100 首）

### 搜索区域（Search）

- 常驻输入框：占满一行
- 搜索逻辑：
  - 过滤字段：标题、内容任意一行包含关键词
  - 输入变化后实时更新 filteredCards
  - filteredCards 为空时显示空态，并禁用翻页/滑动切换
  - 过滤后 currentIndex 自动归零（0），展示过滤结果第一首

### 内容区域（Single Poem View）

- 只渲染当前 1 首古诗
- 推荐结构：
  - 封面（如有：poems 图片）+ 标题 + 作者徽标
  - 正文：按行展示，保持居中与可读性
  - 播放按钮：整首音频播放（沿用现有 handlePlayPoemAudio）
- 内容高度策略：
  - 不限制内容高度
  - 页面整体可纵向滚动（由外层滚动容器承载）
  - 底部吸底翻页条通过增加底部 padding 避免遮挡正文尾部

### 底部区域（Sticky Pager）

- 吸底样式：圆角、厚边框、玻璃质感（沿用项目已有的 clay/glass 风格）
- 控件：
  - 上一首按钮
  - 下一首按钮
  - 进度指示：使用细进度条（当前索引 / 总数）+ 文本（第 x / y 首）
    - 避免 100 个圆点导致密集与不可用

## 交互与状态机

### 翻页（统一入口）

定义两个动作：

- `goPrev()`: 当 filteredCards 非空时，`index = (index - 1 + len) % len`
- `goNext()`: 当 filteredCards 非空时，`index = (index + 1) % len`

触发来源：

- 底部按钮：点击触发 goPrev/goNext
- 左右滑动：在内容区域做横向 drag
  - 阈值：`abs(offsetX) > 80` 或 `abs(velocityX) > 某阈值`（具体值以体感调优）
  - offsetX > 0 视为向右滑（上一首），offsetX < 0 视为向左滑（下一首）
  - 未达阈值回弹

### 搜索

- `searchQuery` 更新 → `filteredCards` 更新
- 过滤结果变化时：
  - `currentIndex` 归零
  - 若正在播放音频：停止当前播放（避免切换列表后音频与 UI 脱节）

### 播放

- 保留整首播放：
  - 点击播放时：播放当前诗的 `audio`（存在则播放 mp3，不存在则降级 TTS）
  - 翻页后：默认停止上一首的播放（更符合“当前页即当前内容”的心智模型）

## 数据与状态

### 数据来源

- 继续沿用当前 poems 数据源（Supabase 的 poems 表）

### 核心状态（建议）

- `cards: CultureCard[]`：原始数据
- `filteredCards: CultureCard[]`：根据 searchQuery 派生
- `currentIndex: number`：当前展示在 filteredCards 中的索引（0..len-1）
- `currentCard: CultureCard | null`：`filteredCards[currentIndex]`（len=0 时为 null）

## 视觉与排版关键点（为“单屏单首”服务）

- 视觉焦点：标题与正文更大、更居中，减少卡片装饰对阅读的干扰
- 控件分层：
  - 顶部负责“导航/搜索”
  - 底部负责“翻页”
  - 中间只负责“阅读 + 播放”
- 间距：在移动端保证正文行距（1.8~2.0）与足够留白

## 边界与异常处理

- filteredCards 为空：
  - 展示空态（保持搜索框可用）
  - 隐藏/禁用底部翻页条
  - 禁用滑动翻页
- 数据加载中：
  - 顶部显示 loading
  - 内容区域显示骨架/占位
- 音频加载失败：
  - 保持 UI 可用
  - fallback 到 TTS 或提示不可播放（保持现有策略）

## 可访问性与可用性

- 底部按钮具备 aria-label（上一首/下一首）
- 键盘支持：
  - PC：左右方向键触发翻页（可选增强）
- 动效可控：
  - 动效时长 200~350ms
  - 尊重 prefers-reduced-motion（可选增强）

## 测试与验收

- 断点：375 / 768 / 1024 / 1440
- 用例：
  - 默认进入古诗：只显示 1 首
  - 左右滑动翻页：循环无卡死
  - 点击底部按钮翻页：循环无卡死
  - 搜索后：只在过滤集合内翻页；清空搜索恢复全集并从第 1 首开始
  - 长诗（如节选类）：页面纵向可滚动，底部吸底不遮挡尾部内容
- 工程校验：`npm run build` 通过
