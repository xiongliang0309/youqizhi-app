# 国学经典-儿歌：C 风格底部抽屉播放器（UI 重构设计）

## 背景

现有「国学经典 → 快乐儿歌」采用网格卡片列表，点击卡片进入全屏播放器。目标是在不改变任何功能逻辑的前提下，打破现有排版，将儿歌体验改为“边逛边播”的 C 风格：底部常驻迷你控制台 + 可展开抽屉播放器。

## 目标

- 保持功能不变：分类选择、搜索、儿歌筛选、列表展示、播放/暂停、上一首/下一首、歌词滚动、点击歌词跳转进度、自动播放尝试、关闭。
- 仅改动儿歌部分：古诗部分 UI/交互保持现状。
- 儿歌页面信息层级更清晰、可浏览性更强：从网格卡片改为高密度列表（单列），让用户更快找到歌。
- 播放体验更连续：播放后不离开列表页，底部出现控制台；需要时上拉展开完整播放器。

## 非目标

- 不改 Supabase/接口/数据结构/字段含义。
- 不新增业务功能（例如收藏、下载、播放队列、倍速、后台播放等）。
- 不调整古诗阅读/朗读逻辑与 UI。

## 核心布局（仅儿歌模式）

### 顶部区域

- 轻量标题栏：返回分类 + 当前分类标题 + 数量徽章。
- 搜索框：占满一行，支持按标题搜索（复用现有 `searchQuery` 逻辑）。
- 儿歌来源筛选：横向胶囊轨道（可横滑），保留现有 `SONG_FILTERS` 与 `activeSongFilter` 逻辑。

### 主体内容

- 儿歌列表改为单列列表项（高密度）：
  - 左侧：封面图（`cover`）或 emoji fallback（`image`），圆角方块。
  - 中间：标题（两行截断）+ 来源/作者小徽章。
  - 右侧：播放按钮（或播放中态）。
- 点击列表项：进入播放（与现有逻辑一致：设置 `currentSongIndex`，并触发播放器打开/播放）。

### 底部区域

- 默认不占位；当 `currentSongIndex !== null` 且存在对应 card 时展示：
  - **collapsed（迷你控制台）**：固定底部，展示封面、标题、播放/暂停、（可选）上一首/下一首、细进度条。
  - 点击控制台或上拉：进入 expanded。

## 抽屉播放器（expanded）

- 高度：约 75–85vh，圆角上边（贴合 claymorphism）。
- 顶部：下拉收起按钮、标题/作者、关闭按钮（关闭 = 停止并退出）。
- 中部：唱片封面（旋转）+ 歌词滚动（可点击跳转）。
- 底部：进度条 + 上一首/播放暂停/下一首。

### 状态与交互

- `collapsed` / `expanded` 两态切换：
  - 上拉/点击迷你条：collapsed → expanded
  - 下拉（拖拽）/点击收起：expanded → collapsed（继续播放）
  - 关闭：停止播放并 `setCurrentSongIndex(null)`
- 播放控制：
  - 播放/暂停、上一首/下一首、进度拖动、歌词点击跳转保持与现有播放器一致。
- 自动播放策略保持：切歌时尝试 `audio.play()`，失败则保持暂停并允许用户手动播放。

## 组件与职责（建议）

- `SongListItem`（可选拆分）：仅负责儿歌列表项的展示与点击反馈。
- `SongPlayerDrawer`（新增）：承载播放器 UI（collapsed/expanded）和播放逻辑。
  - 复用/迁移当前 `MusicPlayer` 的歌词解析、进度、播放控制逻辑。
  - 对外 props：
    - `card: CultureCard`
    - `onClose(): void`
    - `onNext(): void`
    - `onPrev(): void`
- `Culture.tsx`：
  - 儿歌模式使用新列表布局 + `SongPlayerDrawer`。
  - 古诗模式保持现状与现有卡片布局。

## 可访问性与交互细节

- 所有可点击元素具备明确的 focus 样式与 `aria-label`（按钮类）。
- 抽屉展开时：
  - 保持页面可滚动策略明确（推荐：抽屉 expanded 时锁定底层列表滚动，仅抽屉内部滚动歌词）。
  - Esc（可选）：关闭或收起（与现有移动端优先的交互不冲突）。
- 触控拖拽：
  - 支持简单的“向下拖拽收起”，避免过度复杂的手势冲突。

## 响应式规则

- < 768px：单列列表，底部控制台占满宽度。
- ≥ 768px：保持单列（信息密度优先），或在超宽屏适度加大左右内边距即可。

## 视觉风格（与 design-system 对齐）

- Claymorphism：厚边框（3px）、柔和内外阴影、圆角（16–28px）、轻玻璃底。
- 配色：Indigo 主色 + Orange CTA（用于播放/高亮/进度）。
- 动效：150–300ms，避免大幅缩放导致布局抖动；尊重 `prefers-reduced-motion`。

## 验收清单

- 点击儿歌：不离开列表页，出现底部控制台并开始播放（若浏览器允许自动播放）。
- 控制台：播放/暂停、上一首/下一首可用，进度正确。
- 抽屉展开：歌词滚动高亮正确、点击歌词可跳转。
- 关闭：停止播放并退出控制台/抽屉。
- 筛选、搜索与分页加载（如果有）行为不变。
- 古诗模式 UI/交互无变化。
